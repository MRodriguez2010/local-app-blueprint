# Security and support

For a suspected vulnerability, use [private vulnerability reporting](https://github.com/MRodriguez2010/local-app-blueprint/security/advisories/new).
Do not include credentials or personal data in public issues.

Only the latest main branch is maintained, on a best-effort basis. This project
has no production service or support SLA. Run it on a trusted local machine and
review its documented limits before adapting it.
