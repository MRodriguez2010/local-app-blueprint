# Contributing

Start with the README and run its verification commands before proposing a change.
Keep changes small and explain the behavior being fixed, with a reproducible
example or regression test where useful. Use synthetic data in issues and tests.

Report ordinary bugs through GitHub Issues. Report vulnerabilities using the
private reporting route in SECURITY.md. This is a personal project with
best-effort maintenance; there is no support SLA or production warranty.

By contributing, you agree to license your original contribution under MIT.
